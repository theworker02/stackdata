# stackdata

Stack encode/decode helpers for data payloads in pipelines.

**Site:** https://theworker02.github.io/stackdata/

## Install / run

```bash
git clone https://github.com/theworker02/stackdata.git
cd stackdata
node src/cli.js
node --test
```
